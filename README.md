# 📚 The Reading Room Library Management System

A full-stack Library Management System built with Node.js, Express, HTML5, Vanilla CSS, and JavaScript.

## 🔗 Repository & Links
- **GitHub Repository**: [https://github.com/pragathimarpu1205-lab/librarymanagementsystem](https://github.com/pragathimarpu1205-lab/librarymanagementsystem)
- **Local Application Link**: `http://localhost:5000`

---

## ✨ Features
1. **Interactive 3D Book Flipbook Reader**: Read full chapters of books directly in the browser with 3D page flip effects.
2. **Student & Admin Dashboards**: Role-based access for students and library administration.
3. **Automated Gmail & App Password Integration**: Sends real emails for welcome messages, overdue alerts, and book issue receipts using Google 16-letter App Passwords.
4. **SMS Dispatch & Alerts**: Real-time SMS log dispatch for loan issues and due date reminders.
5. **Persistent Storage (`data.json`)**: All student profiles, books, loan records, fines, and transactions persist automatically on disk.
6. **UPI Payment QR Integration**: Collect late fines seamlessly using custom UPI QR codes.

---

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pragathimarpu1205-lab/librarymanagementsystem.git
   cd librarymanagementsystem
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   Navigate to [http://localhost:5000](http://localhost:5000)
